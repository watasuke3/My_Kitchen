## 学習資料の内容

**Scala 側**
- `sealed trait` + `case object/class` — Java の enum との違い、コンパイル時の網羅チェック
- `Either[L, R]` — 例外を使わないエラー処理、なぜ Java の例外より安全か
- `Future[T]` + `map/flatMap` — Java の `CompletableFuture` との対比
- `@Inject` + `@Singleton` + `implicit` — Play の DI 仕組み
- Play Framework のアーキテクチャ (Router → Controller → Service → Repository → DB)
- Evolutions による DB マイグレーション

**TypeScript / React 側**
- Union 型 (`number | null`) — Java の nullable との違い
- React Context — props drilling を避けるグローバル状態管理
- React Router — SPA のページ遷移の仕組み
- ProtectedRoute パターン — 認証ガードの実装方法
- `fetch` + `credentials: 'include'` — Cookie をクロスオリジンで送る方法
- Cookie Session vs JWT — 認証方式の比較
