### データベース設計 (Phase 6)

`shopping_list_items` テーブルを設計しました（主なカラム）:

```sql
CREATE TABLE shopping_list_items (
  id         BIGSERIAL PRIMARY KEY,
  user_id    BIGINT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  name       VARCHAR(255) NOT NULL,   -- 食材名
  quantity   VARCHAR(100),            -- "200g", "2個" など自由記述
  is_checked BOOLEAN NOT NULL DEFAULT FALSE,
  is_preset  BOOLEAN NOT NULL DEFAULT FALSE,  -- プリセット食材フラグ

  ...
);
```

`is_preset = TRUE` のレコードをシステムが初期投入し、ユーザー登録時にコピーします。プリセットも削除・編集可能にして柔軟性を確保しています。
