**試す手順:**

1. Claude Code のプロンプトに直接 `/goal` と入力して Enter — コマンドが実装されていれば起動します
2. もし「コマンドが見つからない」エラーが出る場合は、Claude Code が古い可能性があります

```bash
# Claude Code をアップデートする場合
npm update -g @anthropic-ai/claude-code
```

3. アップデート後に再度 `/goal` を試してください
