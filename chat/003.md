# assistant

Plan モードに入るには以下の方法があります：

## 方法1: `/plan` コマンド（推奨）
Claude Code のプロンプトに直接入力してください：
```
/plan
```

## 方法2: 実装タスクと一緒に依頼
複雑な実装を予定している場合は、「〇〇の実装計画を立てて」と依頼すれば自動的に Plan モードで対応します。

## Plan モードでできること
- **実装戦略の設計** — どのように実装するか
- **ファイル構成の検討** — どのファイルを変更するか
- **アーキテクチャ決定** — トレードオフの検討
- **実装ステップの提案** — 順序立てた作業の流れ
- **ユーザー承認** — 設計に同意してから実装

新機能追加やリファクタリング、大きな変更が必要な場合に活用できます。何か実装予定のタスクはありますか？

# suke
`/plan`モードを解除するにはどうしたらいい？

# assistant

Plan モードを解除する方法は以下の通りです：

## 方法1: `/exit-plan` コマンド（推奨）
Plan モードの最中に、Claude Code のプロンプトに以下を入力してください：
```
/exit-plan
```
このコマンドで Plan モードを終了します。

## 方法2: 通常のコマンド実行
Plan モードでは計画の立案と承認に集中していますが、実装開始時に自動的に通常モードに切り替わります。つまり、計画に同意して実装を始めれば自動的に解除されます。

## Plan モード中の確認事項
Plan モードに入ると：
- プロンプトに **「[PLAN MODE]」** というインジケータが表示される
- 計画をファイルに保存して確認が求められる
- ユーザーの承認が必要になる

計画の検討が終わったら `/exit-plan` で明示的に終了できます。何か実装を進めたいタスクがありますか？
