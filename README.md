# 献立アプリ

## 1. プロジェクト概要
ユーザーの身体情報（性別・身長・体重・年齢・活動レベル）に基づき、最適な1週間の献立を作成・管理する **Webアプリ**。日ごとの献立も作成できる。標準レシピの活用だけでなく、ユーザー独自のカスタマイズや新規登録、栄養フィードバックを通じて、個人の目標に合わせた食生活をサポートする。

## 2. 技術構成
- **対象プラットフォーム**: Webアプリ（PC／スマートフォンのブラウザを想定）。
- **フロントエンド**: TypeScript + React（Vite ベースの SPA）。
- **バックエンド**: Scala 3（Web フレームワークは Play Framework を第一候補）。
- **DB**: PostgreSQL。
- **DBマイグレーション**: Flyway。
- **ビルドツール**: sbt。
- **マルチデバイス**: データはサーバー保存のため、複数端末からの参照・更新が可能。リアルタイム同期や端末固有機能（プッシュ通知等）は将来拡張。
