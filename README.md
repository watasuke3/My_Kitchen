# 献立アプリ

## 1. プロジェクト概要
ユーザーの身体情報（性別・身長・体重）に基づき、最適な1週間の献立を作成・管理するアプリ。（日ごとの献立も作成できるようにする）標準レシピの活用だけでなく、ユーザー独自のカスタマイズや新規登録、栄養フィードバックを通じて、個人の目標に合わせた食生活をサポートする。

## 2. ユーザー属性とログイン
- **認証**: IDとパスワードによるログイン機能（将来的な拡張性を考慮）。
- **セキュリティ**: 個人情報は厳重に管理し、外部への流出を防止する。
- **身体プロファイル**: 性別、身長、体重を登録。
- **自動計算**: プロファイルに基づき「1日あたりの必須カロリー」および「目標栄養素量（PFC等）」を算出。

## 3. レシピ管理機能
- **レシピの種類**:
    - アプリ提供（Preset）
    - ユーザー自作（User-Original）：ゼロからの追加が可能
    - 調整済み（Derived）：既存レシピのコピー＆カスタマイズ
- **分類**: 登録時に「主菜」「副菜」などのカテゴリを選択。
- **具材管理**:
    - メイン食材：数値（g/個など）で管理し、栄養計算に反映。
    - 調味料：テキストメモ形式で管理（こだわりを記録）。

## 4. カレンダー・献立管理機能
- **ウィークリープラン**: 1週間分（朝・昼・晩）の献立を決定。
- **履歴参照**: 過去2週間の食事実績をカレンダー画面から閲覧可能。
- **買い物リスト**: 献立確定後、必要な材料（具材・調味料）のチェックボックス付きリストを自動生成。

## 5. 栄養分析・フィードバック
- **栄養計算**: レシピ内のメイン具材を基に、リアルタイムで栄養価を算出。
- **フィードバック**: 
    - 必須栄養素に対する充足率の提示。
    - ユーザーが指定したタイミング（食後、1日の終わり、週末など）でアドバイスを表示。

## 6. 今後の拡張機能（ロードマップ）
- **パーソナライズ提案**: ダイエット、筋力アップ等、目的に合わせた献立の自動提案。
- **画像認識**: 写真アップロードによる食材の自動判別・記録。
- **栄養オーダー**: 「低糖質」「高タンパク」など、週単位での栄養バランス指定。

## 7. フォルダ・データ構造（開発用）
- `/Users`: ログイン情報・身体データ
- `/Recipes`: 
    - `/Master`: アプリ公式
    - `/User_Collection`: ユーザー自作・カスタム
- `/Schedules`: 献立および過去2週間の実績ログ
- `/Analysis`: 栄養計算ロジック・フィードバック生成
